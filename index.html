Everything here runs against something physical — an industrial camera feed, a humanoid's feet, a Jetson board on a robot at the point of care. That constraint is what the work is about. The recurring theme is not a model architecture, it is refusing to trust a number that has not earned it: the gait reward that quietly rewards marching in place, the validation split that shares images with training, the synthetic dataset that looks like it helped and did not.

01

Humanoid locomotion

G1 Robust Locomotion

public Unitree G1 · 23-DoF PPO / RSL-RL MuJoCo Warp · mjlab trained from scratch

Stand, walk forward and backward, run, and take hits from any direction — trained from scratch, no pretrained policy and no imitation data. Robustness comes from two different disturbances, not one: instantaneous push impulses, and a sustained random-heading drag that holds force for seconds and keeps stealing momentum. A shove and a drag fail a policy in different ways, so each gets its own curriculum, layered over a three-stage command-envelope curriculum so difficulty rises on two axes at once.

Anti-reward-hacking is a design axis. Every gait reward ships alongside the term that closes its exploit — marching in place, foot sliding, hard landings, posture drift. When the policy failed backward pushes, it got a dedicated isolation run and a targeted curriculum fix before any retraining: debugging a policy like a system rather than a slot machine. Trained end-to-end on 2×T4 with a checkpoint/resume harness that survives 9–12 h session kills.

A delta only means something when it clears both its own spread and the class's per-image quantum (1/support). Held to that rule, the honest summary of this experiment is: no macro effect, one small real on-target gain, one small real on-target loss, and a large off-target gain with a mundane explanation.

Melanoma sensitivity is the clinically critical metric in this domain, and +0.116 would have been the headline. The writeup declines to claim it, names the confound, and specifies the balance-matched control (oversampling real rare classes) needed to separate a rebalancing effect from a realism effect. The generation side is built to the same standard: every synthetic image passes memorisation gates before it may be used, and each one is tracked in a provenance manifest flagged synthetic: true.

data-doctor

on PyPI Python · Pillow only CI-gated MIT

A 10-second habit instead of a post-mortem: exact duplicates, near-duplicates, train/val leakage and COCO structural defects (duplicate ids, annotations referencing missing images, degenerate boxes and polygons, zero-annotation images) in one command. Exit code 1 on failure, so it drops straight into CI. Rotated, flipped, re-encoded and resized copies are all caught.

03

Production vision systems

Multi-Model Vision Platform

details withheld Mask R-CNN · RF-DETR-Seg NVIDIA Triton FastAPI + React on-prem GPU

Instance segmentation with metric measurement taken from the masks themselves, served in real time on an on-prem GPU server. The supporting infrastructure is the part that makes the numbers trustworthy: immutable dataset versioning where each version is a complete self-contained snapshot — physical image copies, a canonical manifest, a full audit report, and ready-to-use COCO and Pascal-VOC exports — plus leakage-aware splitting and hard-negative curation. The model registry is licence-constrained by design: permissively licensed components only, because deployment context can rule out copyleft frameworks entirely.

Project details and imagery withheld.

Multi-Service Surveillance Platform

private Jetson shared-memory ring ONNX Runtime ⇄ Triton

Frames flow capture → shared-memory ring → services → renderer with zero pixel copies: the ring is pre-allocated, stages exchange frame descriptors under a lease, and sizing is explicit (ring_slots × max_height × max_width × 3 bytes per camera). Models run in-process on ONNX Runtime by default and can be redirected to Triton; if the server is unreachable at startup, services fall back to local inference rather than failing to start.

Clinical & efficiency research

Pediatric screening robot — clinical perception at the point of care

details withheld Jetson Orin Nano low-data regime FastAPI

An on-robot inference server for congenital anomaly screening, targeting Jetson Orin Nano at the point of care. Conditions are organised behind a registry so each detector is independently versioned, swappable and separately evaluable without touching the serving layer. The project carries its own training stack — augmentation, losses, metrics and callbacks — plus pinned reproducible environments and single-binary packaging for field hardware with no internet connection.
